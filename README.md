Technology Sector Equity Analysis
Overview
This project analyzes historical stock price data from selected technology sector companies — Microsoft (MSFT), NVIDIA (NVDA), and Tesla (TSLA). The analysis focuses on price behavior, volatility comparison, trend analysis, and momentum-based trading insights using Excel-based data analysis and visualization techniques.

Objectives
Analyze historical stock price trends and volatility
Compare performance of major technology sector equities
Identify key market patterns and observations
Develop a simple momentum-based trading idea
Evaluate risks and limitations using historical data
Tools Used
Microsoft Excel
Pivot Tables
Line Charts
Data Analysis & Visualization
Historical Market Data
Key Analysis Performed
Summary statistics analysis (Average, Highest, Lowest prices)
Comparative price trend analysis
Volatility comparison between stocks
Momentum-based trading idea development
Risk and weakness evaluation
Backtesting concept explanation
Key Observations
Microsoft showed relatively stable price movement with moderate decline during the later period.
NVIDIA demonstrated steady upward momentum and gradual price growth.
Tesla exhibited higher volatility with sharp price fluctuations throughout the analysis period.
Files Included
Excel Analysis Workbook
PDF Report
Comparative Charts and Summary Tables
Conclusion
The project highlights how historical stock data can be used to identify market trends, volatility patterns, and potential momentum-based trading opportunities while emphasizing the importance of risk management and historical validation.
